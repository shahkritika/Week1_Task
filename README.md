# Week 1 - Day 1

This repository contains Python practice tasks for Week 1, Day 1. More tasks will be added as the course continues.

## Tasks

- `a1.py` - Create variables and display their types.
- `a2.py` - Convert a number to an integer, float, and string.
- `a3.py` - Reverse a sentence, make it uppercase, and count vowels.
- `a4.py` - Display user information using f-strings.

## Run

Run each task from the project folder:

```powershell
python tasks_day1/a1.py
python tasks_day1/a2.py
python tasks_day1/a3.py
python tasks_day1/a4.py
```
