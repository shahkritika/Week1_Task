# Day 2 Python Tasks

This folder has 4 simple Python programs.

## 1. Even Numbers
`a1.py`
- Takes a number N
- Prints all even numbers from 1 to N

## 2. Sum Until Zero
`a2.py`
- Asks for numbers again and again
- Stops when the user enters 0
- Prints the total sum

## 3. Minimum, Maximum, and Average
`a3.py`
- Takes 3 numbers
- Finds the smallest, largest, and average
- Shows the result with 2 decimal places

## 4. Celsius to Fahrenheit
`a4.py`
- Takes temperature in Celsius
- Converts it to Fahrenheit
- Prints the result

## Run a file
```bash
python a1.py
python a2.py
python a3.py
python a4.py
```
